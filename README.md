# 🚀 Responsive Internship Board

A responsive and accessible internship listing interface built using
semantic HTML, CSS3 and vanilla JavaScript.

## 📌 Internship Task

Full Stack Development Internship - Task 1

## 🎯 Objective

Build an accessible internship listing interface that works across
mobile, tablet and desktop devices without using a frontend framework.

## ✨ Features

- Responsive internship listing
- Semantic HTML5
- Reusable internship data
- Dynamic DOM rendering
- Search internships
- Filter by domain
- Filter by work mode
- Clear filters
- Loading state
- Empty state
- Error state
- Retry functionality
- Internship details dialog
- Application form
- Email validation
- HTTPS portfolio URL validation
- Duplicate application prevention
- Keyboard accessibility
- Responsive mobile layout
- Tablet layout
- Desktop layout

## 🛠️ Technologies Used

- HTML5

- JavaScript
- Git
- GitHub
- GitHub Pages
